# My Fridge

Chọn thực phẩm bạn đang có, nhận thực đơn sáng – trưa – tối vừa đủ calo để kiểm soát cân nặng.

## Chạy thử trên máy

```bash
npm install
```

```bash
npm run dev
```

Mở http://localhost:3000 trên trình duyệt.

## Kiểm tra lỗi trước khi đưa lên

```bash
npm run build
```

Xem thêm mô tả dự án và quy tắc làm việc trong [CLAUDE.md](./CLAUDE.md).
